The name

A global name with an Indian soul

Spanda is Sanskrit for the subtle pulse that sets stillness in motion. A Spanda website is still until the viewer scrolls, and then it comes alive, scene by scene.

Positioning and pillars

What Spanda stands for

For designers, developers, agencies and creators who want cinematic, scroll-driven 3D websites without generic templates, Spanda is a local-first desktop studio that directs an idea and references into an original story, then builds, tests and exports real HTML or React code you own. There's no lock-in, no backend required, and every export ships with its test results and license report.

Pillar Direction

It asks like a director, not a form.

  • One visual question at a time, always skippable
  • Two to four original visual directions to choose from
  • You approve the brief and storyboard before anything is built
Pillar Craft

Cinematic and correct.

  • Screenshots in Chromium, Firefox and WebKit on desktop, tablet and phone
  • Accessibility and performance checks on every build
  • Reduced-motion and no-WebGL fallbacks built in
Pillar Ownership

Your story, your code, your machine.

  • Runs locally; your projects never need a cloud account
  • Exports plain HTML or React source with no lock-in
  • License and asset provenance report with every export
Logo

The Kolam S

One unbroken line loops around two dots and forms an S. In South India a kolam is drawn at the doorstep each morning: a single line weaving around a grid of dots. Here the dots are scenes and the line is the scroll that carries you from one to the next. The dots glow Diya, like lamps placed on a kolam. Western viewers see a clean S monogram; anyone who knows kolam sees the tradition. Hover the logo at the top to replay its one motion.

Color

Night, Neel and one lamp

The accent is Neel. "Indigo" comes from the Greek indikón, "from India", because the dye did, so the color carries the same quiet origin story as the name. The studio uses the same tokens, so the brand and the app read as one. Click a swatch to copy its hex.

Diya is the warm glow of an oil lamp: the two dots of the logo, plus at most one marketing highlight per composition. It never appears in the studio UI, where it would look like the warning state.

Typography

System fonts, drawn wordmark

The studio works offline and ships no font licenses, so text uses each platform's own system font. The wordmark will be drawn as outlined SVG; the version on this page is set in the system font as a placeholder.

Open core

Free studio, paid add-ons

Spanda Studio

Free · Apache-2.0 (proposed) · public GitHub

  • The full idea → storyboard → website → export pipeline
  • HTML and React export, tests, license report
  • Works with the Claude Code or Codex CLI you already use

Spanda Pro Add-ons

Paid · commercial EULA · separate repo

  • One paid brand; each add-on gets a plain English name
  • Pro Scene Library, Pro Team Review, and more later
  • Installs into the free studio through a public add-on API

Our promises

  1. The core stays free. A feature that's free today never moves behind Pro.
  2. Your output is yours. Exported sites have no watermark and no attribution requirement, free or Pro.
  3. No resold AI access. You bring your own provider. Pro sells features, not tokens.
  4. Works offline. Pro license checks run locally.
