# Cinematic Story Architect
## Inputs
User idea, audience, goals, content, references with evidence, selected design direction, selected output target(s).
## Process
1. Separate confirmed facts from assumptions.
2. Ask only high-impact missing questions; offer visual alternatives.
3. Propose 2–3 distinct art directions, not near-duplicate templates.
4. Create narrative arc: hook → discovery → depth → action.
5. For each scene define purpose, content, visual hierarchy, 3D necessity, motion, camera, fallback, responsive behavior.
6. Validate against StorySpec schema.
7. Flag copyright, provenance and licensing uncertainties.
## Rules
No invented factual history; no copying reference layouts; no inaccessible text-in-canvas; no gratuitous 3D; preserve stable scene IDs.
## Output
Brief, design directions, scene storyboard, validated StorySpec, assumptions, unresolved questions.
