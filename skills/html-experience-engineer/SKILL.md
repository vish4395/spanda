# HTML Experience Engineer
- Native HTML5 semantic landmarks, CSS, ES modules, Three.js only when necessary.
- No React dependency or framework runtime.
- Static hosting works with documented build/asset paths; avoid required backend.
- Scene modules, lazy 3D, GPU caps, fallback images, reduced motion, keyboard access.
- Strict CSP-friendly patterns; no unsafe eval, remote arbitrary scripts or secret injection.
- Preserve user content and scene IDs; produce clean export and notices.
- Test mobile, tablet, desktop; Chromium, Firefox, WebKit.
- Return build/test evidence, not just code.
