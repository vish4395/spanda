# React Experience Engineer
- React + Vite + strict TypeScript, small composable components, R3F/Drei for appropriate scenes.
- No backend required for static build; no studio-specific runtime.
- Stable scene IDs, clear data/content separation, code splitting, lazy assets.
- React lifecycle cleanup for observers, animation loops, events and GPU resources.
- Responsive camera/quality settings, no-WebGL fallback, reduced-motion, keyboard support.
- Validate dependencies and licenses; preserve notices and provenance.
- Typecheck, lint, build, browser screenshot/interaction tests.
- Return evidence and report unsupported StorySpec features.
